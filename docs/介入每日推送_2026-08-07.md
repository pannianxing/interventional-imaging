### 一、中国肝细胞癌经动脉介入治疗临床实践指南（2026版）

- **来源**：中国医师协会介入医师分会（CCI）临床诊疗指南专委会 /《中华医学杂志》
- **发布日期**：2026年6月2日
- **原文链接**：https://rs.yiigle.com/cmaid/1677458
- **DOI**：10.3760/cma.j.cn112137-20260211-00457

**核心要点总结**：

本指南是CCI在2018/2021/2023版TACE指南基础上的重大升级，由滕皋军院士牵头，**首次将TACE、HAIC、SIRT三大经动脉介入治疗（TAI）技术整合进同一部指南**。指南采用GRADE分级和牛津循证医学中心证据分级，经5轮专家共识会议制订。

关键更新点：
1. **TACE**仍是不可切除HCC首选方法，CNLC Ⅱb/Ⅲa期首选推荐，单次碘化油用量不超过20mL，强调肝段/亚段超选择性栓塞；
2. **HAIC**正式纳入正文，明确适用于肝内高肿瘤负荷（最大径≥7cm或伴脉管癌栓），推荐以FOLFOX方案为基础的持续灌注；
3. **SIRT**首次从附录跃升为正文核心技术，适应证包括剩余肝脏体积不足的CNLC Ⅰb/Ⅱa期、肝移植桥接、多发病灶伴门静脉癌栓等；
4. 入路选择：股动脉入路仍为常规，但**经桡动脉入路可改善患者舒适度**（证据等级2），对技师DSA操作提出了新的体位和参数调整要求；
5. 强调MDT为核心、个体化综合治疗，TAI联合靶向免疫治疗为未来方向。

**与血管机培训的关联**：SIRT术中需DSA配合CBCT进行钇-90微球灌注区域确认和肝肺分流评估，HAIC需DSA引导下留置导管，这两项技术的培训需求将显著增加。经桡动脉入路TACE对技师C臂角度调整、路图设置提出新要求，需纳入培训体系。

- 时效性：✅ 2026年6月发布，为最新版
- 相关性：✅ 直接涉及DSA引导下TAI操作规范、CBCT导航、入路技术
- 去重：✅ 为CCI官方唯一版本，替代2018/2021/2023版

### 二、2026 AHA/ASA急性缺血性卒中早期管理指南

- **来源**：美国心脏协会（AHA）/美国卒中协会（ASA）/《Stroke》期刊
- **发布日期**：2026年1月26日
- **原文链接**：https://www.ahajournals.org/doi/10.1161/STR.0000000000000513
- **DOI**：10.1161/STR.0000000000000513

**核心要点总结**：

这是自2018版以来AHA/ASA卒中指南的**首次重大更新**，更是首部系统纳入儿童卒中介入治疗的国际指南。基于SELECT2、ANGEL-ASPECTS、ATTENTION等十余项里程碑式临床试验，中国主导的10项关键研究被纳入，占比38%。

关键更新点：
1. **EVT适应症大幅扩展**：从传统小核心、前循环、6h窗口扩展至大核心梗死（ASPECTS 3-5）、后循环基底动脉闭塞、24h延长窗及既往轻中度残疾（mRS 0-2）人群；
2. **替奈普酶（TNK）**正式与阿替普酶并列推荐，因单次推注方便，更适合桥接场景；
3. **首次纳入儿童卒中推荐**：≥6岁儿童LVO可在6h内行EVT，24h内若影像显示可挽救组织也可考虑；MRI/MRA为首选诊断工具；
4. **血压管理更新**：EVT后不推荐强化降压至SBP<140mmHg（可能有害），即使达到TICI 3级完全再灌注；
5. 不推荐神经保护剂、不推荐紧急颈动脉干预、不推荐IVT后辅助抗栓药物（阿加曲班/依替巴肽）。

**与血管机培训的关联**：指南扩展了EVT适应症至大核心梗死和后循环，这对DSA操作提出更高要求——技师需熟悉CTP/DWI影像筛选标准、ASPECTS评分，掌握双平面DSA在后循环取栓中的操作技巧。24h延长窗意味着夜间急诊取栓将更频繁，技师需具备全天候响应能力。

**【自检通过】**
- 权威性：✅ AHA/ASA官方发布，Stroke期刊刊载，全球卒中领域最高级别指南
- 时效性：✅ 2026年1月发布，为自2018年以来的首次重大更新
- 相关性：✅ 直接涉及DSA引导下机械取栓操作规范、影像筛选标准、技术参数
- 去重：✅ AHA/ASA官方唯一版本，取代2018版及2019年更新

### 三、CIRSE/SIR联合指南：介入放射学职业防护（2026版）

- **来源**：欧洲心血管与介入放射学会（CIRSE）/ 美国介入放射学会（SIR）/《CVIR》&《JVIR》联合刊载
- **发布日期**：2026年2月13日
- **原文链接**：https://link.springer.com/article/10.1007/s00270-025-04195-4
- **JVIR链接**：https://www.jvir.org/article/S1051-0443(26)00009-6/fulltext

**核心要点总结**：

这是**时隔16年对2010版职业防护指南的首次重大更新**，由CIRSE和SIR联合制定，内容从单纯辐射防护扩展至整体职业健康管理。

关键更新点：
1. **新增CT引导介入和放射性栓塞（SIRT）的防护章节**，反映介入放射学操作范围的扩展；
2. **新增肌肉骨骼损伤（MSK）防护章节**，首次系统关注介入医生和技师的职业性骨科损伤（颈肩腰劳损），推荐符合人体工程学的操作台和铅衣设计；
3. **孕期工作人员辐射防护**专节，明确孕期可继续从事介入工作但需额外监测（胎儿剂量<1mSv）；
4. 推荐使用**0.5mm铅当量防护装备**（包括铅眼镜），强调整体团队防护而非仅个人防护；
5. 剂量监测建议：双剂量计（铅衣内+铅衣外），每年眼科检查（白内障筛查）。

**与血管机培训的关联**：**这是与培训工程师工作最直接相关的指南**。培训工程师自身就是辐射高危人群，且承担着向技师和医生传授防护知识的职责。新指南中MSK防护、SIRT防护、CT引导防护三项新增内容，应纳入常规培训课程。此外，培训中应强调DSA设备的低剂量模式（如飞利浦ClarityIQ/SmartIQ、西门子Optiq）的正确使用。

**【自检通过】**
- 权威性：✅ CIRSE/SIR两大国际权威学会联合发布，CVIR+JVIR双刊刊载
- 时效性：✅ 2026年2月发布，为2010版以来首次更新
- 相关性：✅ 直接涉及介入医生和技师的职业防护，是培训工程师必须掌握的内容
- 去重：✅ CIRSE/SIR官方联合唯一版本

**内容概要**：

全球两大DSA厂商在2026年上半年相继发布重磅技术更新，核心方向均为AI驱动的图像质量与辐射剂量优化：

**西门子**在ECR 2026发布Artis genio、Artis icono.explore、Artis icono.vision三大新平台，搭载三大AI功能：①Syngo DynaCT MORE——迭代重建CBCT，自动消除呼吸/心跳运动伪影；②myEmbolization Guide——器官特异性AI栓塞规划（肝脏/前列腺/通用），自动三维肿瘤轮廓勾画+供血/非供血血管区分；③Optiq AI成像链——AI实时降噪，同剂量下更高图像质量。

**对培训工程师的影响**：新一代DSA设备的AI功能（AI栓塞规划、CBCT运动校正、AI降噪）将深刻改变操作流程，培训内容需从传统的"手动参数调节"转向"AI辅助工作流管理"。CBCT-P技术若普及，技师需掌握灌注成像的基本原理和操作流程。
